# HIKYAKU

**Note: This project is currently under development.**

HIKYAKU is a file transfer service built with Flask. The development environment is set up using Docker.

## Project Structure

- `templates/` folder: Stores HTML templates.
- `static/` folder: Stores static files such as CSS, JavaScript, and images.

## How to Run

1. Build and start the Docker container:
   ```bash
   docker-compose up --build
   ```

2. Access the service at `http://localhost:58080`.

## Features

- Upload files via a web interface.
- Download files directly from the server.
